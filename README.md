# Карта приключений (DnDMapHelper)

**Версия 0.99 beta** · WPF-приложение для мастера настольных ролевых игр: карта, метки, маршруты, квесты и свитки с описаниями.

Мастер готовит сессию на своём экране, игроки смотрят на отдельное окно — второй монитор, проектор или телевизор.

## Возможности

- **Карта** — загрузка изображения, масштаб, прокрутка (колёсико, WASD, ползунки)
- **Метки партии и целей** — щит отряда и медальоны точек интереса
- **Маршруты** — очередь путей с плавным контуром и анимацией движения отряда
- **Области** — контуры мест на карте со свитками описаний (видимость для игроков настраивается)
- **Столкновения** — точки боёв: свиток открывается, когда отряд проходит мимо
- **Квесты** — цели, точка сдачи, области выполнения; журнал на экране игроков
- **Экран игроков** — отдельное окно с синхронизацией карты, движения и квестов
- **Сохранение сессии** — один файл `.dndmap` (карта + все метки, маршруты и квесты)

## Быстрый старт

1. **Открыть** — загрузить сохранение `.dndmap` или **Карта** — выбрать новое изображение карты.
2. **Партия** — клик по карте, где стоит отряд.
3. **Цель** — медальоны точек, куда можно идти.
4. **Путь** — провести линию к выбранной цели; маршрут попадёт в очередь.
5. **▶** — открыть окно для игроков.
6. **⚔** — запустить движение отряда по первому маршруту в очереди.

Подробная справка встроена в программу: кнопка **?** внизу окна мастера.

## Формат `.dndmap`

Файл сохранения — ZIP-архив:

| Файл внутри | Содержимое |
|-------------|------------|
| `map.png` | Изображение карты |
| `session.json` | Метки, маршруты, квесты и настройки сессии |

Используйте **Сохранить** / **Открыть**, чтобы не потерять подготовленную сессию между играми.

## Два экрана

| Экран мастера | Экран игроков |
|---------------|---------------|
| Все инструменты, квесты, маршруты, столкновения | Карта, видимые метки, текущий маршрут |
| Управление движением отряда | Журнал квестов (только чтение) |
| Редактирование областей и текстов | Свитки при клике по области или проходе мимо боя |

Квесты управляют тем, что видят игроки: активный квест показывает невыполненные цели, «Готов к сдаче» — только точку сдачи, «Выполнен» — скрывает связанные метки.

## Структура репозитория

```
DnDMapHelper/
├── DnDMapHelper/          # исходный код WPF-приложения
│   ├── Controls/          # карта, журнал квестов
│   ├── Views/             # окна мастера, игроков, редакторы
│   ├── Services/          # сессия, сохранение, движение
│   ├── Models/            # метки, маршруты, квесты
│   └── Help/              # тексты справки и «О программе»
└── DnDMapHelper.slnx
```
